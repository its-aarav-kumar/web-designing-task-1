# Task 1 – Responsive Personal Portfolio Homepage

## Objective
Create a responsive personal portfolio homepage using HTML5 and CSS3.

## Technologies
- HTML5 semantic elements
- CSS3
- Flexbox and responsive media queries

## Sections
Home/Hero, About, Skills, Education, Projects, Contact form, Footer.

## How to run
1. Open this folder in Visual Studio Code.
2. Open `index.html` in your browser, or use the Live Server extension.
3. Test desktop and mobile layouts.

## Customize before submission
- Replace the sample email address.
- Confirm your education details and project descriptions.
- Add your own profile image if desired (place it in `images/` and update HTML).
- Add your real LinkedIn and GitHub URLs.
- Take screenshots and put them in `screenshots/`.

## Contact form
This is a front-end demonstration form. It is not connected to a backend and will not send messages.
